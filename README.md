# Music Release Checklist

A simple release checklist for independent music creators.

## Before publishing, check:
- [ ] Exact song title and artist name confirmed
- [ ] Thumbnail matched to the song, not mixed up
- [ ] Description written, no download links in public text
- [ ] Video marked Public and Not made for kids (where applicable)
- [ ] Captions, title and hashtags added for Reels
- [ ] Catalog entry updated

Demo project prepared for the Codex Ambassador application.
